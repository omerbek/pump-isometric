# Isometric Pump / Pompa gövdesi

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/pump-isometric/).

Bir pompa gövdesinin izometrik blok taslağında parçaları ayır.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Patlatılmış görünüş mesafesi
- Eğim derinliği

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Adjust the separation and depth of an exploded pump sketch.

Open [the live tool](https://omerbek.github.io/pump-isometric/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
